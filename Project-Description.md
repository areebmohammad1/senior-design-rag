## Project Topic Area
Applied Artificial Intelligence & Natural Language Processing (Local RAG Architecture with Epistemic Citation Tracing)

## High-Level Overview
Designing a local, privacy-preserving AI knowledge copilot using hybrid Retrieval-Augmented Generation (RAG) and open-source LLMs. The system implements an epistemic tracing pipeline to eliminate generative hallucinations through sentence-level source attribution and verifiable provenance across local document repositories.
